## 2. Защищённый просмотрщик (чистый HTML/JS, без сборщика)

Создай файл `legal.html` — **отдельная секция `#specialists`** уже существует, встрой туда; если проще — создай `specialist.html?id=alagyan` как единый шаблон.

**Логика:** при клике на карточку `.tcard` в `index.html` — переход на `legal.html#alagyan` (или `specialist.html?id=alagyan`).

**Защита документов (реализовать всё вместе):**
- PDF рендерятся через **PDF.js** (`pdfjs-dist` CDN) в `<canvas>` — текст нельзя выделить и скопировать.
- `user-select: none` на всю страницу просмотрщика.
- Отключить контекстное меню: `document.addEventListener('contextmenu', e => e.preventDefault())`.
- Блокировать сочетания клавиш `Ctrl+S`, `Ctrl+P`, `Ctrl+Shift+S`, `PrintScreen` (через `keydown`).
- CSS: `@media print { body { display:none } }` — печать заблокирована.
- Атрибут `<a>` нигде не содержит прямых ссылок на PDF-файлы; маршрут только через JS.
- 100% защиты от скриншотов на уровне браузера не существует — это приемлемый компромисс, указать заказчику.

**Структура страницы специалиста (минимум):**
- Фото специалиста (из `img/team-<slug>.jpg`)
- ФИО, должность
- Список документов с человекочитаемыми названиями (диплом, сертификат и т.д.) — названия задать вручную по содержимому файлов
- Каждый документ — кнопка «Открыть», рендерит PDF в модальном окне поверх страницы через PDF.js canvas
- Кнопка «Закрыть» и клик вне модала — закрывают просмотрщик

## 4. Тестирование сайта

Открыть `index.html` локально и проверить (можно через `npx serve` или `python3 -m http.server`):

**Функциональное:**
- [ ] Все ссылки навигации ведут в правильные секции
- [ ] Модальные окна (попапы услуг) открываются и закрываются
- [ ] Карточки специалистов кликабельны и ведут на страницу специалиста
- [ ] Кнопки CTA (`href="tel:..."`) корректны
- [ ] Форма обратной связи (если есть) валидируется
- [ ] Ссылка на лицензию `docs/license.pdf` работает

**Адаптивность:**
- [ ] 320px (iPhone SE) — нет горизонтального скролла, текст читаем
- [ ] 768px (планшет) — сетки перестраиваются корректно
- [ ] 1280px+ — десктоп выглядит как задумано

**Скорость и базовая SEO:**
- [ ] Все `<img>` имеют атрибут `alt`
- [ ] Есть `<title>`, `<meta name="description">`
- [ ] `robots.txt` и `sitemap.xml` существуют в корне

Результаты тестов дописать в тот же `AUDIT_REPORT.md` секцией `## Тестирование`.
